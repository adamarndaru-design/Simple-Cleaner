# Simple Cleaner

Cleaner sederhana untuk semua HP Android (min. Android 5.0).

## Cara build APK

### A. GitHub Actions (tanpa install apa-apa, bisa dari HP)
1. Buat repo baru di github.com, upload SEMUA isi folder ini (termasuk folder `.github`).
2. Buka tab **Actions** -> **Build APK** -> **Run workflow**.
3. Setelah hijau (±3-5 menit), buka run-nya, download artifact **SimpleCleaner-APK**, ekstrak, install `app-debug.apk`.

### B. Android Studio
File -> Open -> pilih folder ini -> tunggu sync -> Build -> Build APK(s).

## Izin
Android 11+: aktifkan "Izinkan akses semua file" saat diminta.
